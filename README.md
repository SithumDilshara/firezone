# FireZone

Gaming guide and giveaway app for Free Fire players.

The app publishes guides, daily rewards, and custom rooms. It is not affiliated with Garena. This repository is the project record. It does not contain source code.

## What it does

- Publishes game guides for players
- Runs giveaways and custom rooms
- Handles sign-in, notifications, and in-app access

## Stack

Flutter, Dart, Firebase Authentication, Firebase Realtime Database, Firebase Cloud Messaging, PHP, MySQL, Google Sign-In

## Where to get it

[Google Play](https://play.google.com/store/apps/details?id=com.firezone.lk)
